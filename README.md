# A counterexample to Songsuwan’s Conjecture 2 in Node-Kayles

A fixed connected 291-vertex host with repeated endpoint-rooted five-vertex paths has game values 8 and 9 at counts 4j+5 and 4j+7 for every natural j. Hence no eventual lag-two equality holds on this host.

Songsuwan’s Conjecture 2 fixes a graph G, a vertex u of G, and a level-regular rooted tree H. For each k, join the roots of k disjoint copies of H to u by fresh edges. The conjecture predicts an onset N after which the Grundy value at k equals the value at k+2 for every k ≥ N. Here G and u are fixed for the entire sequence. The five-vertex path rooted at an endpoint is level-regular with branching vector (1,1,1,1), and each copy attaches to u by exactly the prescribed edge. For any proposed N, take j=N. The two counts 4j+5 and 4j+7 are beyond the onset and differ by two, yet their values are 8 and 9. The host contains cycles, so the tree-only Conjecture 1 remains open. [Songsuwan, Section 4](https://arxiv.org/html/2512.24221v2#S4)

The standalone Challenge defines the board, closed-neighborhood game and both targets. The Solution derives them from the construction and finite recurrence certificate. With Elan installed, run `lake exe cache get` and `lake build`. The official preflight uses the root `comparator.json`.
